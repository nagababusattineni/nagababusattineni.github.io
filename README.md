# nagababusattineni.github.io

Personal resume site for Nagababu Sattineni — Senior SDET at DP World.

Single-file static site (`index.html`, no build step) hosted on GitHub Pages at
https://nagababusattineni.github.io once this repo is pushed to GitHub.

`Nagababu_Sattineni_Resume.pdf` is the downloadable resume linked from the page.
`.build/generate_resume_pdf.py` regenerates it (requires `reportlab`; not needed to serve the site).
